# Sahib redesign reference prototype

This is a standalone exploratory HTML prototype for Sahib, not production code.

## Open it
Open `index.html` in a browser. Use the left navigation to move between 14 screens. Use the top-right controls to switch light/dark mode and theme family. Tasbih has a working sample counter; other controls provide lightweight prototype feedback.

## Screens
- Home
- Daily Practice
- Reminders & personal routines
- Adhkar browser
- Focused Adhkar session
- Prayer timetable
- Hijri calendar
- 99 Names grid
- Name detail
- Library
- PDF reader
- Tasbih
- Search
- Settings

## Important caveats
- Content is illustrative sample data and must not be treated as verified religious text, a prayer timetable, or a religious ruling.
- The reminder screen is a product-design concept. Any religious claims, intervals, or wording must be verified against trusted sources before production use.
- Theme and accent support here is illustrative, not an exact reproduction of the production app's current theme architecture.
- Use the prototype as inspiration, not as a binding spec or a substitute for the existing app's architecture.
- The DeepSeek prompt is in `DEEPSEEK_FLASH_4.1_REDESIGN_PROMPT.md`.
