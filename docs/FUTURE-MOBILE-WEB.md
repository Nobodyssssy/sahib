# Future mobile and web roadmap

Planning only. Windows feature development is frozen; no Android project or SDK is being added.

## Android, when development resumes

- Build a dedicated mobile-first interface, preserving the independently designed mobile experience.
- Share Sahib's data, application logic, storage concepts, themes and content with Windows/web.
- Add native Android integrations only when mobile development begins.

## Website, in a future phase

- Base mobile/tablet layouts on the future mobile interface and desktop layouts on the Windows desktop interface.
- Adapt layout to viewport size and interaction capabilities.
- Share JavaScript logic, data, content and the existing PDF engine; avoid duplicate applications.
- The website runs independently in the browser and never requires the Windows executable.
