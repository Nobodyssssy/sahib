## What's changed

- **Native taskbar integration:** Sahib's compact prayer widget now sits inside Explorer's taskbar while keeping its existing design, prayer data and expanded panel.
- **No jumping when Start opens:** pressing the Windows key keeps the native widget in the same taskbar slot.
- **Safer positioning:** the widget avoids Windows controls and other embedded widgets. A crowded taskbar uses a compact fallback above the bar, then re-embeds when space returns.
- **Better display handling:** improved per-monitor DPI, monitor-local fullscreen hiding, taskbar auto-hide and recovery after Explorer restarts.
- **Clearer light mode:** black prayer/time/countdown text and dark secondary labels, including the large Countdown Focus digits; corrected native theme-token selection.
- **Lifecycle fixes:** corrected keyboard panel re-entry and monitor-switch cleanup while preserving the accepted shutdown fix and short expanded-panel cache.

## Verification

Validated on Windows 11 with two physical displays at 100% and 125% DPI: 30 Rust tests, native hosting/Start/fullscreen/auto-hide checks, an actual Explorer restart, English/Arabic light/dark layouts, monitor-switch cleanup, all 14 shutdown cases and all 8 panel lifecycle checks.

The native-only idle sample averaged about 72 MiB working set (19 MiB private resident) and 0.43% system CPU over 36 seconds on the test desktop, with no WebView descendants. These are short measured samples, not a performance guarantee or a claimed CPU improvement over v0.2.4.
