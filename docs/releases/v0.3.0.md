## What's changed

- **New desktop design:** a calmer editorial look across the app, Arabic and English, light and dark. The sidebar mirrors to the right in Arabic. Home shows a scene that follows the current prayer phase.
- **Adhkar:** the page now opens on what fits the time of day, with a quiet "Today" progress column, then the categories in six groups as a contents list. Sessions cap the count at the target; Space advances, Backspace undoes.
- **Daily Practice:** the Today tab is a dated agenda. Prayer times form the spine and each practice sits at its anchor (for example 30 minutes after Fajr). Rare actions sit behind a menu. The other tabs keep their previous design.
- **99 Names:** spaced-repetition review (a "Today" deck of due names plus five new), larger flashcards and keyboard control.
- **Library:** the PDF reader gains a real contents panel, in-book search, page notes, and single-key shortcuts (press ? for help).
- **Taskbar widget:** new "Awqat" style (default for fresh profiles) with name/clock and countdown columns, a colour fill before a prayer and after it, a blinking border until acknowledged (optional), and an elapsed label ("Asr · 6 min ago"). Existing profiles keep their saved style.
- **Tasbih:** Space or Enter counts.
- **Fixes:** the finished session timer no longer expands or focuses the widget (it grew the floating widget before); restoring the last page after reopening from the widget no longer leaves Practice blank; widget placement and a stored repeating timer were corrected; the sidebar no longer disappears at the 900 px minimum window width.
- **Desktop only:** the old PWA code (service worker, manifest, install prompts, unused styles and functions) is removed. The minimum window width is now 900 px. French is not included in this release.

## Verification

Checked on Windows 11 with an isolated QA build of the same code: 38 Rust tests, 17 unit tests, release checks, native widget tests (16 for the Awqat widget, 11 for the earlier fixes, 18 for the timer in three widget modes, 10 for opening Practice from the widget), and browser checks in English and Arabic, light and dark, at 1440 and 900 px.

## Download and notes

Download **Sahib_0.3.0_x64-setup.exe** for 64-bit Windows. The accompanying `.sha256` file verifies the installer checksum. The installer is unsigned.

The packaged installer itself was built and checked for version and checksum but not run; the upgrade over an existing install was not exercised. Not tested: Windows 10, multiple monitors, a real mouse click on the taskbar widget, and the user's own practice data. Two reported bugs (a doubled Adhan and the Adhkar daily reset) could not be reproduced; the related code was hardened but their cause is unconfirmed.

This release updates `codex/windows-tauri`; `main` is unchanged.
